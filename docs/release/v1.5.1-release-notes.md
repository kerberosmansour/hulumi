# v1.5.1 Release Notes

This release publishes all six `@hulumi/*` packages atomically at `1.5.1` through
npm trusted publishing with SLSA Build L3 provenance.

## What ships

- `@hulumi/platform-patterns.BrokeredAuroraPostgresBoundary`: inert Pulumi
  scaffolding for four disjoint Kubernetes/IRSA identities, closed network paths,
  immutable workload envelopes, value-free secret containers, public inline JWKS
  configuration, admission controls, and encrypted replay state.
- `@hulumi/policies/platform/packs/brokered-postgres-boundary`: structural preview
  checks for the boundary.
- `HULUMI-H3` fail-closed classification for boundary roles with missing or unknown
  workload identity kinds.
- CycloneDX 1.6 capability claims with explicit limits.

## What does not ship

This release does not implement the authorization broker, PostgreSQL bootstrap,
migrator, rotation executable, conditional replay claim, or live IAM/Kubernetes/
PostgreSQL proof. Consumers must supply and verify those pieces. The component is
inert until the consumer records its reviewed activation evidence.

## Release gates

Before tagging `v1.5.1`, run:

```bash
pnpm install --frozen-lockfile
pnpm run lint:exact-pin-guard
pnpm -r build
pnpm -r typecheck
pnpm -r test
pnpm -r lint
pnpm run lint:license-boundary
pnpm run format:check
```

After the tag workflow publishes, verify all six package versions and attestations.
