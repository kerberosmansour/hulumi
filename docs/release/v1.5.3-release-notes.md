# v1.5.3 Release Notes

This patch publishes all six `@hulumi/*` packages atomically at `1.5.3` through
npm trusted publishing with SLSA Build L3 provenance.

## What changed

- The intentionally suspended migrator `Job` created by
  `BrokeredAuroraPostgresBoundary` now carries the Pulumi Kubernetes
  `pulumi.com/skipAwait: "true"` annotation.
- Pulumi creates the object without waiting for a readiness state that a suspended
  `Job` cannot reach.

## Safety boundary

This changes deployment mechanics only. The migrator `Job` remains
`spec.suspend: true`, the rotation `CronJob` remains suspended, and every
`Deployment` remains at `replicas: 0`. The release does not start workloads,
scale nodes, increase timeouts, or add runtime authority. Activation remains an
explicit consumer operation followed by live IAM, Kubernetes, network, and
PostgreSQL verification.

## What does not ship

This release still does not implement the authorization broker, PostgreSQL
bootstrap, migrator, rotation executable, conditional replay claim, or live
effective-authorization proof. Consumers must supply and verify those pieces.

## Release gates

Before tagging `v1.5.3`, run:

```bash
pnpm install --frozen-lockfile
pnpm run lint:exact-pin-guard
pnpm -r build
pnpm -r typecheck
pnpm -r test
pnpm -r lint
pnpm run lint:license-boundary
pnpm run format:check
```

The pull-request artifact dry run must also pass. After the trusted tag workflow
publishes, verify all six package versions, six SBOMs, six attestations, and
public release assets.
