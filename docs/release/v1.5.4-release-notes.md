# v1.5.4 Release Notes

This patch publishes all six `@hulumi/*` packages atomically at `1.5.4` through
npm trusted publishing with SLSA Build L3 provenance.

## What changed

- The brokered PostgreSQL mandatory policy pack compares structured Kubernetes
  values using canonical object-key ordering while preserving array order.
- NetworkPolicy twins ignore only measured Kubernetes server metadata and
  normalize a provider-omitted `spec.ingress` to the declared empty list.
- The policy recognizes Pulumi's typed
  `kubernetes:vpcresources.k8s.aws/v1beta1:SecurityGroupPolicy` token.

## Safety boundary

The normalization is deliberately narrow. Consumer-authored metadata and the
rest of each policy spec remain part of the comparison. Arrays remain
order-sensitive. Explicit `null` ingress is not treated as an empty list.
Incorrect resource types, API versions, and kinds still fail closed.

This release changes policy evaluation only. It does not start workloads,
increase timeouts, weaken the authority boundary, or add runtime access.

## What does not ship

This release still does not implement the authorization broker, PostgreSQL
bootstrap, migrator, rotation executable, conditional replay claim, or live
effective-authorization proof. Consumers must supply and verify those pieces.

## Release gates

Before tagging `v1.5.4`, run:

```bash
pnpm install --frozen-lockfile
pnpm run lint:exact-pin-guard
pnpm -r build
pnpm -r typecheck
pnpm -r test
pnpm -r lint
pnpm run lint:license-boundary
pnpm run format:check
```

The pull-request artifact dry run must also pass. After the trusted tag workflow
publishes, verify all six package versions, six SBOMs, six attestations, and
public release assets.
