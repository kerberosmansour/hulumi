# Hulumi v2.0.3

Hulumi 2.0.3 fixes live Kubernetes admission for protected Pods selected by an
AWS VPC `SecurityGroupPolicy`.

The AWS VPC resource mutating webhook adds one toleration to those Pods:
`vpc.amazonaws.com/pod-eni`, with operator `Exists`, effect `NoSchedule`, no
value, and no duration. The protected envelopes previously allowed only the
configured workload-pool toleration and Kubernetes's two standard 300-second
`NoExecute` tolerations, so the legitimate fourth entry was denied closed.

`BrokeredAuroraPostgresBoundary` and `WorkloadCapabilityIssuerBoundary` now
admit only that exact AWS-added toleration in addition to the existing exact
set. Unknown tolerations and changes to the key, operator, value, effect, or
duration remain denied.

All six `@hulumi/*` packages remain on the atomic `2.0.3` release train.
