## Review verdict

Proceed with repository implementation under the exact M3 allow-list. The plan
is safe to implement locally because it needs no cloud mutation. Live provision
stays blocked until the merged readiness job passes. The admitted controller
image may publish first because its exact digest is the live qualification
input; coordinated npm/package version 3.1.0 publication stays blocked until all
live outcomes and teardown evidence are green. No critique finding authorizes a
dependency, policy exception, shared cluster or release.
