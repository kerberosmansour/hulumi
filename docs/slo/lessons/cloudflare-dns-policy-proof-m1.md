# Lessons: Cloudflare DNS-only policy proof M1

- A component type token can locate candidate evidence, but it is not the evidence itself.
- Stack validation is necessary when an exception depends on parent inputs; resource validation cannot inspect or correlate the parent object.
- Parent identity, in-stack presence, hostname equality, and the exact acknowledged state must be checked together.
- Keeping the stable rule ID while changing its evaluator preserves policy configuration and reporting continuity.
