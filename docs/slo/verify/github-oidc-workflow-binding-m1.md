## Residual limits

- This milestone prepares trust documents and migration guidance; it does not mutate a live GitHub OIDC template or AWS role.
- GitHub organization templates do not automatically affect repositories. Each repository must opt in with `use_default: false` or apply its own template.
- Existing deployments need a coordinated fail-closed cutover or a separately named parallel role. G_OIDC_1 intentionally rejects old/new subject arrays because every array member is an alternative authority.
- The constructors keep `reusableWorkflowRef` optional in the v3 TypeScript declaration so existing consumers receive an explicit runtime migration error instead of a declaration-only failure. Runtime construction always requires it; a future major may make the property statically required.
- The separate finding about Pulumi preview unknown values is outside this milestone and remains tracked independently.
